连续测量当前浏览器到 PureIP 节点的 HTTP 往返延迟、抖动和请求失败率，并提供参考下载速度；不计入 IP 纯净度总分。

IP 详情

这个 IP 的“身份证”：归属网段、运营商域名、住宅 / 机房属性、精确位置，以及你的浏览器指纹与 WebRTC 泄漏情况。

多源地理核对

用多个数据源交叉核对归属地与类型（住宅 / 机房 / 移动）。几家信息越一致越可信；差异大说明这个 IP 定位模糊。

风险评分

各威胁情报库给这个 IP 打的“欺诈分”，0 最好、100 最差。多个库都低说明干净；分高说明被标记为代理 / 滥用。

DNS 黑名单（共享/滥用检测）

查这个 IP 是否上过垃圾邮件 / 滥用黑名单。命中说明它被人滥用过——常见于被很多人共用的“万人骑”IP。

AI / 流媒体解锁实测

用这个出口真实访问各服务，看能否打开、落地在哪个地区。“可用”才代表这条线路能正常使用该服务。
